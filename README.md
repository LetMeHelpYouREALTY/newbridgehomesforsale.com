# New Bridge Homes For Sale

Next.js App Router site for [newbridgehomesforsale.com](https://www.newbridgehomesforsale.com) — Las Vegas real estate with Dr. Jan Duffy (BHHS Nevada Properties).

## Stack

- Next.js 15 (App Router)
- React 19 + TypeScript
- RealScout office listings widget
- Vercel deployment

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Local development server |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |
| `npm run type-check` | TypeScript check |
