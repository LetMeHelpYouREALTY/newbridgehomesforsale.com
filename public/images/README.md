# Image Assets Guide

Photographs in `hero/`, `sections/`, and `neighborhoods/` were generated for each page heading (Las Vegas homes, buying, selling, luxury, 55+, new construction, investment, relocation, valuation, office, condos, open houses, sold, and neighborhood landscapes). They are JPEG, max 1920px wide.

Use `next/image` with `sizes` and `priority` on LCP heroes. Alt text should name the place or property type, not a protected class.
